# LearnEase

LearnEase is a multi-model teaching tool that:

- Accepts any topic/keyword as input.
- Lets learners choose preferred methodology, language, and visual style.
- Generates guided lesson content and an infographic-style summary.
- Runs a post-learning quiz to measure understanding.
- Captures feedback for continuous improvement.
- Maintains continued-learning history without logins using a device/IP-based identifier.

## Run

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://localhost:8000
